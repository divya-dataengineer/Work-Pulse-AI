# WorkPulse AI Demo Script

## Scenario

A project manager wants to review a recent project meeting and quickly identify action items, risks, and next steps.

---

### User Input

Summarize the following meeting discussion:

John will prepare the sales dashboard by Friday.
Sarah will update the Power BI report by Monday.
The client approval is still pending.
The team discussed budget allocation and deployment timelines.

---

### WorkPulse AI Response

## Summary

The team reviewed dashboard development progress, reporting updates, budget planning, and deployment timelines.

## Action Items

* John: Prepare sales dashboard by Friday.
* Sarah: Update Power BI report by Monday.

## Risks

* Client approval is pending.
* Deployment timeline may be affected by approval delays.

## Recommendations

* Follow up with the client regarding approval status.
* Track dashboard and reporting deliverables before the next review meeting.

---

### User Input

Identify project risks from this discussion.

---

### WorkPulse AI Response

## Risk Analysis

High Priority Risks:

* Pending client approval.
* Potential delay in deployment activities.

Recommended Actions:

* Escalate approval request if not received within 48 hours.
* Create contingency planning for deployment schedules.

---

### User Input

Recommend next steps.

---

### WorkPulse AI Response

## Follow-up Recommendations

1. Confirm dashboard completion by Friday.
2. Verify Power BI report updates by Monday.
3. Obtain client approval.
4. Schedule a project status review meeting.
5. Monitor deployment readiness.
